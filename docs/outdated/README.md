# Archived documentation

The files in this directory are retained as historical drafts. They are part of the
repository-wide documentation audit, but they are not current usage guidance and do
not define the present public API.

Each archived file must identify any known difference from current supported behavior;
the archive label is not permission to leave an unmarked contradiction.

Before restoring one of these pages to the generated documentation, reconcile it with
the current source, tests, maintained examples, and V-model, then add it to
`docs/make.jl`.

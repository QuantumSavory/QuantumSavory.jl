## Interactive metadata catalogs

The public, non-exported functions
`QuantumSavory.available_slot_types`,
`QuantumSavory.available_background_types`, and
`QuantumSavory.constructor_metadata` are available after loading the
`InteractiveUtils` and `REPL` standard libraries. The type catalogs recursively
discover concrete subtypes from every currently loaded package, retain usable
parametric constructors, and include a type only when its canonical defining
binding is public. Results are recomputed and sorted by qualified type name on
every call, so loading another package updates the next result immediately.

Slot and background entries contain `(type, doc)`. Constructor entries contain
`(field, type, doc)` and omit undocumented or underscore-prefixed fields. See
[Predefined Networking Protocols](@ref) for the opt-in protocol catalog.

# Repository Workflows

Open one playbook for the repository operation being performed.

| Need | Open | Do not open |
|---|---|---|
| Select and run the repository test entry points | [Testing](testing.md) | Understanding subsystem behavior without running checks |
| Build or review human-facing documentation | [Documentation](documentation.md) | Source-only changes with no documentation impact |
| Validate runnable examples and their wrappers | [Examples](examples.md) | Unit-test or benchmark-only tasks |
| Run focused benchmarks or interpret automation | [Benchmarking](benchmarking.md) | Functional correctness work |

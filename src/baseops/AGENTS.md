# Base Operations Router

For initialization, composition, application, observables, time advancement, or
traceout, open:

- [register operations reference](../../.agents/context/core/register-operations.md)
- [register model](../../.agents/context/core/register-model.md) when ownership or
  factorization changes
- [time and noise](../../.agents/context/simulation/time-and-noise.md) for temporal

Preserve state back-references and explicit subsystem order. Check both symbolic
and numeric paths and every affected backend capability. Use focused selectors
such as `general/apply`, `general/observable`, or `general/traceout`.

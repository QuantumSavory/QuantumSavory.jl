# CircuitZoo Router

Open the [circuits catalog](../../.agents/context/zoos/circuits-catalog.md) for
existing building blocks. Open
[add a circuit](../../.agents/context/zoos/add-circuit.md) only for implementation
work.

Circuits operate immediately on slots and may consume or replace state. Verify
supported representations, success/failure branches, exports, and the matching
`general/circuitzoo` test prefix.
